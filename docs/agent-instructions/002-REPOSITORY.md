# 🗂️ 002 — Правила работы с репозиторием

> 📌 Здесь — как агент должен работать с Git и структурой проекта,
> чтобы правки гарантированно доезжали до сервера.

---

## 1. 🌿 Ветки и коммиты

- ✅ Рабочая ветка агента: `arena/*` или `feat/*` → Pull Request в `main`.
- ✅ `main` — **единственная** ветка, из которой работает авто-деплой.
- ✅ Прямые пуши в `main` допустимы только для «горячих» фиксов (hotfix).
- ✅ Коммиты: `feat: ...`, `fix: ...`, `docs: ...`, `chore: ...` + краткое описание.
- ✅ Один коммит = одна логическая единица работы.
- ❌ Нельзя: коммитить `node_modules`, `dist/`, кэши, большие артефакты.

---

## 2. 📂 Где что лежит

- 📚 `docs/agent-instructions/` — инструкции для агентов (правки → сервер `/root/agents/`).
- 🚀 `deploy/` — скрипты установки/обновления сервера.
- ⚙️ `deploy/github-actions/deploy.yml.example` — шаблон авто-деплоя; активируется копированием в `.github/workflows/deploy.yml`.
- 🧩 `src/` — код браузера (модули: security, proxy, vpn, profiles, sessions, cookies, vision).
- 📝 `CHANGELOG.md` — обновлять при заметных изменениях.
- 📄 `README.md` — главное описание проекта и инструкции.

---

## 3. 🔐 Секреты и токены в репозитории

- ✅ Секреты — только в GitHub Secrets (`DEPLOY_HOST`, `DEPLOY_USER`, `DEPLOY_SSH_KEY`, `AGENT_TOKEN`).
- ✅ В коде — переменные окружения `${VAR}` / `${{ secrets.* }}`.
- ✅ `.env*` и `*.pem`, `*_key`, `ghp_*` — в `.gitignore` (файл уже добавлен).
- ❌ Никогда не открывать секреты в ответах пользователю.
- ⚠️ Если секрет утёк в чат/коммит — немедленно его **отозвать** и пересоздать.

---

## 4. 🔄 Синхронизация инструкций на сервере

- 📚 Источник истины — `docs/agent-instructions/` **в Git**.
- 🖥️ На сервере — `/root/agents/` (зеркало, обновляется деплоем).
- 🔄 Деплой: `deploy/server-update.sh` копирует `docs/agent-instructions/*` в `/root/agents/`.
- ✅ Агент **всегда** правит в Git, а не на сервере напрямую.
- 📊 После деплоя — проверить: `ls -la /root/agents/ && cat /root/agents/001-GENERAL.md | head`.

---

## 5. ✅ Чек-лист перед push/PR

- [ ] 📖 Инструкции прочитаны
- [ ] ✍️ Изменения минимальны и по задаче
- [ ] 🔐 Секретов в диффе нет
- [ ] 🧪 Локальные проверки зелёные
- [ ] 🚀 Шаблон `deploy/github-actions/deploy.yml.example` актуален и корректен
- [ ] 📢 Пользователь уведомлён о результате
