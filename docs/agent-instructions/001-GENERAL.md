# 📚 001 — Общие инструкции Октопус для агентов

> 🧭 Действуют для **всех** агентов, работающих с проектом Octopus Browser
> (ChatGPT + GitHub-плагин, Arena, Claude, Gemini, Codex и др.),
> а также на сервере — зеркалируется в `/root/agents/`.

---

## 1. 🗣️ Формат ответа (жёсткие правила)

- ✅ **Только маркированные списки** — каждый тезис отдельным пунктом `-`.
- ✅ **Визуальная наглядность**: заголовки `##`, таблицы, код-блоки, цитаты `>`.
- ✅ **Эмодзи-акценты** в каждом блоке смысла (см. словарь ниже).
- ✅ Структура ответа: `1) Вывод → 2) Что сделано → 3) Как проверить → 4) Что дальше`.
- ✅ Если действий много — нумерованный список **по шагам**, не «простыня».
- ✅ Русский язык, если пользователь пишет по-русски.
- ❌ Без: сплошных абзацев, «стены текста», ответов без структуры.
- ❌ Без: повторов одного и того же в разных формулировках.

| 🧪 | Тесты | «🧪 Тесты прошли» |

---

## 3. 🧠 Стиль мышления и работы

- 🔍 **Сначала разведка** — прочитать инструкции, осмотреть код, только потом менять.
- 🎯 **Одна задача = один коммит**; коммит-сообщения `feat:` / `fix:` / `docs:`.
- 🧱 **Минимальные правки**: не трогать то, что не относится к задаче.
- 🧪 **Проверка до деплоя**: линт/тесты/сборка; деплой — только после зелёного статуса.
- 🗣️ **Сообщать понятно**: что изменено, где лежит, как проверить, что дальше.
- 🤝 **Спрашивать** при неоднозначности: уточняющий вопрос лучше неверного предположения.

## 4. 📋 Шаблон отчёта агента

```markdown
- 🤖 **Статус:** {выполняется / выполнено / блок}
- 📌 **Задача:** {одна строка}
- ✅ **Сделано:**
  - {пункт}
  - {пункт}
- 🔍 **Как проверить:** {команда/шаг}
- ⚠️ **Замечания:** {риски/уточнения}
- 🚀 **Что дальше:** {следующий шаг}
```

## 5. 🚫 Запреты

- ❌ Секреты, ключи, токены — в чат, коммиты, логи.
- ❌ Прямые изменения на сервере в обход `deploy/`.
- ❌ Удаление/переименование файлов без согласования с задачей.
- ❌ «Тихий» деплой без уведомления пользователя.
