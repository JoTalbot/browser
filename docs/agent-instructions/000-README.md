## 🧭 Как пользоваться

- 🤖 Агент читает `AGENTS.md` + нужный файл по задаче.
- 📌 Инструкции **в Git** — источник истины; на сервере `/root/agents/` — зеркало.
- 🔄 Изменения инструкций → push в `main` → авто-деплой на сервер.
- ⚠️ Секреты в инструкции **не** включать.
