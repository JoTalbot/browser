## 🖼️ Пример ответа агента

- 🤖 **Статус:** ✅ Задача выполнена.
- 🎯 **Задача:** добавить авто-деплой GitHub → сервер.
- 📌 **Что сделано:**
  - ✅ Созданы инструкции `AGENTS.md` и `docs/agent-instructions/*`.
  - ✅ Добавлен workflow `.github/workflows/deploy.yml` — push в `main` → сервер.
  - ✅ Добавлены скрипты `deploy/server-bootstrap.sh` и `deploy/server-update.sh`.
- 🔍 **Как проверить:**
  - 📌 В GitHub: `Actions → Deploy Octopus` — статус запуска.
  - 📌 На сервере: `ls -la /root/agents/ && cat /root/agents/001-GENERAL.md`.
- ⚠️ **Замечания:**
  - ⚠️ Требуется заполнить Secrets: `DEPLOY_HOST`, `DEPLOY_USER`, `DEPLOY_SSH_KEY`.
  - ⚠️ SSH-ключ и PAT, отправленные в чат, рекомендуется **отозвать**.
- 🚀 **Что дальше:** настроить Secrets → запустить первый деплой → проверить сервер.

## 📏 Правила оформления

- ✅ Маркированные списки `-`, вложенность через 2 пробела.
- ✅ Заголовок задачи + эмодзи-статус в первой строке.
- ✅ Таблицы — только когда данные табличные (сравнение, перечень файлов).
- ✅ Код-блоки — для команд, YAML, конфигов.
- ✅ Эмодзи в начале смыслового блока; не «эмодзи-салат» в середине предложения.
- ✅ Русский язык; технические термины — допустимы английские.
- ❌ Не более 1 смыслового блока на 1 пункт; без длинных абзацев.
