# 🏗️ Архитектура Octopus Browser

> 🐙 Супербезопасный браузер с ИИ-управлением. Адаптер экосистемы
> Октопус (`JoTalbot/AIOS`, `JoTalbot/octopus`).

---

## 1. 🧩 Общий контур

```text
┌──────────────┐   задача   ┌─────────────────┐   действия   ┌──────────────┐
│  Пользователь │ ─────────▶ │ 🤖 OctopusAgent │ ────────────▶ │ 🧭 Браузер    │
│  / ИИ-агент   │ ◀───────── │  (vision-цикл)  │ ◀──────────── │ (Playwright) │
└──────────────┘  результат  └─────────────────┘  скриншоты   └──────────────┘
        ▲                                              │
        │           HTTP API (FastAPI)                 ▼
        └───────── 📡 /octopus/info, /agent/run ── 🗄️ Профили, Сессии, Куки
```

---

## 2. 📦 Модули (`src/octopus_browser/`)

| Модуль | Ответственность |
|---|---|
| `config.py` | ⚙️ Настройки из env, пути данных |
| `core/launcher.py` | 🌐 Playwright: запуск, human-pacing, скриншоты |
| `profiles.py` | 👥 Мульти-профили (изолированные user-data) |
| `sessions.py` | 🔑 Сессии: save/load/export/import storage_state |
| `cookies.py` | 🍪 Cookies: CRUD, экспорт/импорт |
| `network.py` | 🌍 Прокси-ротация (ProxyManager) + VPN-интерфейс |
| `vision.py` | 👁️ Vision: описание кадра, решение (JSON-план) |
| `agent.py` | 🤖 Цикл агента: кадр → решение → действие |
| `api.py` | 🔌 FastAPI: REST + адаптер Октопус |
| `main.py` | 🚀 Точка входа (uvicorn) |

---

## 3. ⚙️ Черты «супербезопасности»

- 🔐 Секреты — только окружение/GitHub Secrets; `.gitignore` блокирует утечки.
- 🛡️ Отдельный профиль на задачу — изоляция cookies/сессий.
- 🧱 Whitelist действий агента (`ACTIONS`) — нельзя выполнять произвольные команды.
- 🚦 Лимит шагов (`max_steps`) — защита от «зацикливания» ИИ.
- 🌐 Прокси/VPN на каждый запуск; проверка здоровья узлов.

---

## 4. 🤖 Управление ИИ с «человеческой» скоростью

- 👁️ Vision: скриншот → описание → JSON-план.
- 🕒 `HumanPacer`: случайные задержки 0.4–1.6 c, «пошаговая» печать.
- 🧠 История последних действий — контекст для решений.
- ✅ Остановка: цель достигнута (`done`) или лимит шагов.

---

## 5. 🐙 Интеграция с Октопусом (AIOS)

- 📡 Эндпоинт `GET /octopus/info` — метаданные и capabilities адаптера.
- 🔌 `POST /agent/run` — запуск задачи из любого оркестратора Октопуса.
- 🔄 Авто-деплой: push в `main` → GitHub Actions → сервер `git pull` + apply.
- 📚 Инструкции: `docs/agent-instructions/` ↔ `/root/agents/` на сервере.
